Publiczny serwer MCP

Serwer odpowiada na zapytania o publiczne ogłoszenia przetargowe. Nie wymaga logowania, nie używa ciasteczek i nie widzi Twojej rozmowy z asystentem AI: dostaje tylko argumenty wywołanego narzędzia, np. słowa kluczowe, kody CPV i daty.

O każdym zapytaniu zapisujemy:

  • czas, metodę protokołu i nazwę narzędzia lub zasobu;
  • argumenty narzędzia (np. szukane słowa i filtry), liczbę wyników, czas odpowiedzi i rodzaj błędu;
  • nazwę i wersję klienta MCP oraz nagłówek User-Agent;
  • anonimowy identyfikator klienta: skrót adresu IP z losową solą, która istnieje tylko przez bieżący dzień (UTC) i jest potem usuwana. Identyfikatorów z różnych dni nie da się połączyć, a samego adresu IP nie zapisujemy.

Szczegółowe zapisy usuwamy po 90 dniach. Wcześniej zamieniamy każdy zakończony dzień na zestawienie dzienne (liczby zapytań i błędów, liczba różnych klientów, czasy odpowiedzi według narzędzia), bez argumentów i identyfikatorów; zestawienia przechowujemy bezterminowo.

Dziennik serwera WWW zapisuje czas, żądanie, kod odpowiedzi, rozmiar, czasy obsługi i User-Agent, bez adresu IP, i jest usuwany po 14 dniach. Limit liczby zapytań trzyma adres IP wyłącznie w pamięci serwera przez kilka minut.

Cel: działanie i bezpieczeństwo usługi, ochrona przed nadużyciami oraz ulepszanie narzędzi. Podstawa: prawnie uzasadniony interes administratora (art. 6 ust. 1 lit. f RODO). Prosimy nie wpisywać do zapytań danych osobowych; nie są potrzebne do wyszukiwania ogłoszeń.

Formularz kontaktowy

Zapisujemy imię lub nazwę firmy (jeśli je podasz), adres e-mail i treść wiadomości, wyłącznie po to, żeby odpowiedzieć. Nie zapisujemy adresu IP ani User-Agent. Wiadomość usuwamy najpóźniej po 12 miesiącach, a na prośbę wcześniej. Podstawa: art. 6 ust. 1 lit. f RODO (odpowiedź na Twoje pytanie). Podanie adresu e-mail jest dobrowolne, ale bez niego nie odpowiemy.

Privacy policy

Effective 21 November 2026

This policy covers the tenderkit.pl website, the public MCP server mcp.tenderkit.pl (including its use as a connector in Claude and other MCP clients) and the contact form. The tenderkit library installed on your own computer sends us no data.

Controller

Public MCP server

The server answers queries about public procurement notices. It requires no sign-in, sets no cookies and never sees your conversation with an AI assistant: it receives only the arguments of the tool that was called, such as keywords, CPV codes and dates.

For each request we record the time, protocol method and tool or resource name; the tool arguments, result count, duration and error class; the MCP client name and version and the User-Agent header; and an anonymous client ID, a hash of the IP address with a random salt that exists only for the current UTC day and is then deleted. IDs from different days cannot be linked, and the IP address itself is never stored.

Detailed records are deleted after 90 days. Each finished day is first rolled up into daily totals (request and error counts, number of distinct clients, latency per tool) without arguments or IDs, which are kept. Web server logs hold the time, request, status, size, timings and User-Agent, without IP addresses, for 14 days. Rate limiting keeps IP addresses only in server memory for a few minutes.

Purpose: operating and securing the service, preventing abuse and improving the tools. Legal basis: legitimate interest (Art. 6(1)(f) GDPR). Please do not put personal data in queries; searching notices does not need any.

Contact form

We store your name or company (if given), e-mail address and message, only to reply. We do not store your IP address or User-Agent. Messages are deleted after at most 12 months, or earlier on request. Legal basis: Art. 6(1)(f) GDPR.

Website

The website sets no cookies. It is hosted on GitHub Pages, and GitHub may log visitor IP addresses under its privacy statement. Page views are counted with Cloudflare Web Analytics, which uses no cookies and does not track visitors across sites; we see aggregate numbers only.

Processors and sharing

OVH SAS (OVHcloud) hosts the MCP server and the contact form in an EU data centre; GitHub, Inc. hosts the website; Cloudflare, Inc. provides aggregate page-view statistics. We do not sell data, show ads or share data with anyone else unless the law requires it.

Notice data

The server republishes public notices from the Polish Public Procurement Bulletin (BZP) and TED as the buyers published them, including names of contractors and contact persons. To report an error or ask for data to be removed from our copy, write to kontakt@tenderkit.pl.

Your rights

You have the right to access, rectify, erase and restrict processing of your data, to object, and to lodge a complaint with the Polish supervisory authority (Prezes Urzędu Ochrony Danych Osobowych). Telemetry IDs are anonymous and change daily, so we usually cannot link them to a person (Art. 11 GDPR).
