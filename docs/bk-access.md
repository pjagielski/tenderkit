# Access to Baza Konkurencyjności (BK2021)

Checked on 2026-11-13 against the production service run by the Ministry of Development Funds and Regional Policy.

## Published access

The official user guide describes a notice search available without signing in. The notice page also offers a PDF of that individual notice. The help site describes email notifications in the signed-in account. We found no published external API specification, API registration process, bulk export, or RSS feed for BK2021 in the operator's materials or the national open-data catalogue. The archive is a separate service. ## Observed portal endpoints

The operator's frontend uses `/api/announcements/search` for its public search. A small anonymous read for publication date 2026-11-12 with status `PUBLISHED`, `page=1`, `limit=2`, and `sort=default` returned two records in `data.advertisements` and `data.meta.total=169`. The response body was JSON with an HTTP `text/html` content type. The total describes that query at the time of the read. The sample covers one status and the current BK2021 instance. [Operator frontend bundle](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/assets/index-D3ELI812.js) · [Sample search URL](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/api/announcements/search?page=1&limit=2&sort=default&status%5B0%5D=PUBLISHED&publicationDateRange%5Bfrom%5D=2026-11-12&publicationDateRange%5Bto%5D=2026-11-12)

Anonymous GET of `/api/announcements/297288` returned the notice details, including orders and the public attachment list. The file resource is identified by the nested `attachments[].file.id`. In this sample it is `3190753`, and HEAD of that file returned HTTP 200 and `application/pdf`. The check transferred headers only. Use the file identifier linked by the public notice and distinguish attachments to the notice from documents in an offer or internal workflow. ## Reuse conditions

The production portal's regulation response marks the current text with publication date 2026-05-13. Chapter II points 3–4 describe the portal's purpose as enabling the competitive procurement procedure, including publication, discovery, reading and bidding. Point 5 applies the Ministry's public-sector information reuse policy to use for another purpose. It requires naming the full source, **Ministerstwo Funduszy i Polityki Regionalnej**, stating the date the information was obtained, and disclosing any processing. A Tenderkit record can carry all three alongside its canonical source URL. [BK2021 regulations](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/regulamin) · [Regulation text returned to the public frontend](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/api/regulations)

We found no express rule in the current regulation requiring prior approval for automated reading of public notice metadata, forbidding it, or specifying an automation quota. Chapter VI regulates account access and prohibits using someone else's credentials. Chapter VII distinguishes the publisher's own rights from third-party rights and provides a licence to the Ministry for certain works. Chapter VIII puts responsibility for lawful reuse on the recipient. Polish public-sector reuse law also limits reuse where privacy or third-party rights apply. A public attachment URL establishes that the file can be read. Its publication does not establish a general licence to republish it. [BK2021 regulations, chapters VI–VIII](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/regulamin) · [Polish public-sector reuse law, Art. 5–6 and 39](https://eli.gov.pl/eli/DU/2023/1524/ogl)

For Tenderkit, the observed routes support a bounded read of public notices with source attribution, acquisition date and a processing note. Detail responses include contact and account fields unrelated to this purpose, so cache only the fields needed for notice discovery and for identifying public attachments. Treat an incomplete or changing result set as a failed refresh. Keep attachment fetches on demand and use the public references surfaced by the notice. The Ministry support contact for asking about a supported feed or quotas is `konkurencyjnosc@mfipr.gov.pl`. [Official support contact](https://www.gov.pl/web/nfosigw/faq5)

## Tenderkit verification

On 2026-11-13, `fetch --source BK --profile oprogramowanie --from 2026-11-12 --to 2026-11-12` stored 28 notices. The CPV dictionary yielded 450 full codes for the two profile prefixes. The five search batches reported 17, 11, 1, 10 and 8 results. The union of their identities matched all 28 SQLite identities in a separate read using a larger page size. The queries covered published, closed, resolved and cancelled notices. These counts apply to this specific test and can change as records are revised.

For public notice `297288`, the document workflow listed seven references and downloaded file `3190753` into a temporary content-addressed store. The file was a 440,908-byte PDF and passed SHA-256 verification. [Public notice](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/ogloszenia/297288)

The portal labels the order budget in PLN. Tenderkit keeps available estimates on each lot and uses a single non-variant order's estimate at notice level. A notice-level value remains empty where the response gives no unambiguous overall budget. [Operator frontend](https://bazakonkurencyjnosci.funduszeeuropejskie.gov.pl/assets/index-D3ELI812.js)
